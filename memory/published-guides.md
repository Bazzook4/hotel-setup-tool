## Internal Linking Strategy

When creating new guides, look for natural linking opportunities:

### Revenue Guides → Link to:
- Rate linkage when discussing multiple rate plans
- OTA guides when discussing channel-specific rates
- Channel Manager when discussing multi-platform rate management
- RevPAR/ADR when discussing pricing strategy
- No-Show when discussing non-refundable rates

### OTA Guides → Link to:
- What is OTA (foundational guide)
- Rate linkage for managing OTA rates efficiently
- Channel Manager for multi-OTA management
- TDS & TCS for tax compliance on OTA bookings
- OTA Commission Calculator tool
- OTA Dependency Calculator tool

### Software Guides → Link to:
- Channel Manager ↔ OTA guides
- PMS ↔ Reports guides
- RMS ↔ Revenue metrics (ADR, RevPAR, Occupancy)
- Booking Engine ↔ Direct bookings, reducing OTA dependency

### Compliance Guides → Link to:
- GST ↔ Accounting Software
- TDS/TCS ↔ OTA guides
- Reports guides for compliance documentation

### Cross-Category Links:
- **Genius Program** → Rate linkage, Channel Manager, What is OTA
- **Rate Linkage** → Booking.com guide, Agoda guide, Channel Manager
- **No-Show** → Booking Engine, Revenue metrics
- **Channel Manager** → All OTA guides, Rate linkage, PMS
